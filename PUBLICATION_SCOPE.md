# Publication scope

This public release contains analysis scripts, input contracts and dependency notes for the SIGLEC1 recurrent glioblastoma transcriptomic study. The manuscript remains under revision. Raw matrices, specimen-level derived tables, credentials and confidential correspondence are excluded. Using the accompanying supplementary tables, the release verification recomputes 41 expanded-cohort rank tests and six original-label expression tests and checks BH families and concordance arithmetic. It does not certify a clean-room raw-data pipeline rerun or clinical/causal biomarker validation.
