# Public sources and required inputs

GEO records: [GSE200984 discovery](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE200984), [GSE174554 external nuclear](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE174554), [GSE339484 paired tissue](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE339484), [GSE139533 paired tissue](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE139533), [GSE254873 NanoString](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE254873), [GSE254145 spatial](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE254145), [GSE274546 CARE](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE274546), [GSE212067](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE212067), [GSE4271](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE4271), and [GSE7696](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE7696).

CGGA uses the 20200506 release. For each of `693` and `325`, retrieve `CGGA.mRNAseq_NUMBER_clinical.20200506.txt.zip` and `CGGA.mRNAseq_NUMBER.RSEM-genes.20200506.txt.zip` from [CGGA downloads](https://www.cgga.org.cn/download.jsp). Store both files under the corresponding input override. These are unpaired adult IDH-wild-type grade IV GBM/rGBM tissue comparisons, not longitudinal pairs.

The original GSE200984 annotation workspace is [reconvolving_gbm_workspace.RData](https://drive.google.com/file/d/1LmQX3vD6voSvO3dTbG9b2kY-kW3U-dhP/view), linked from [the original study scripts](https://github.com/adithyakan/reconvolving_gbm). Verified bytes: 5,393,219,005. SHA-256: `3763b43b985ebacb8375a8461de87a213a08761a29cc38dfe28f19e87614c0cc`. The original paper's Supplementary Dataset 1 supplies the Case-to-TB map, exported as `data/metadata/GSE228500_patient_metadata.tsv`. This file contains the source clinical specimen mapping, not newly inferred pairing.

For GSE174554 and CARE author metadata use [GBM-CARE-WT data](https://github.com/dravishays/GBM-CARE-WT/tree/main/data): `diaz_cell_md_20240820.RDS`, `diaz_clinical_snrna_metadata_20240106.txt`, `celltype_meta_data_2025_01_08.RDS`, and `spitzer_supptable1.xlsx`. Original-label metadata inputs required by the analysis are `GSE174554_author_celltype_map.csv` (CellID, SampleID, UCSF_ID, CellType), `GSE174554_original_clinical.csv` (ID, Pair., Age, IDH, Diagnosis, Stage), `celltype_meta_data_2025_01_08.csv` (CellID, ID, CellType), and `CARE_original_clinical.csv` (Sample ID, Patient ID, Time point, Age at initial diagnosis, IDH Status). Export the original RDS data frames with `write.csv`, preserve the original specimen/barcode columns, and use the source clinical table rather than inferring stage from identifiers. No caller should silently fabricate missing fields. Public-source clinical tables used by the revision are supplied in the supplement; original large annotation files are retrieved from their own source, not redistributed here.

The tissue scripts read:

```text
data/raw/GSE339484/GSE339484_counts_All_Samples.txt.gz
data/raw/GSE139533/GSE139533_mergede_protein_coding_counts.tab.gz
data/raw/GSE254873/GSE254873_processed.txt.gz
data/raw/GSE254145/GSE254145_SpatialTranscriptomics_normalized_log2_cpm.xlsx
data/reference/gencode.v50.basic.annotation.gtf.gz
data/metadata/GSE139533_paired_tissue_manifest.csv
```

Discovery analysis additionally reads the processed outputs `data/processed/GSE200984_myeloid_reclustered.h5ad`, `data/processed/GSE200984_strict_basic_atlas_cnv.h5ad`, and the barcode-level source QC and marker tables generated by the preprocessing scripts. These intermediate matrices are not bundled. GSE174554 raw libraries require `<SampleID>_matrix.mtx.gz`, `<SampleID>_features.tsv.gz`, and `<SampleID>_barcodes.tsv.gz`. CARE requires the deposited `_<ID>_umi_counts.RDS.gz` files under its raw override.

The array-validation scripts retrieve exact series matrices and GPL mapping records with `fetch_metadata.py` and `fetch_matrices.py`. Historical probe mappings, duplicate or unavailable outcomes and eligibility limits remain explicit in the supplementary result tables. The companion derived tables allow rank-test verification without downloading raw matrices. They are not published in this code-only repository. Preserve the companion paths `Revision/analysis_tables`, `Revision/recurrence_marker_reassessment/analysis_tables`, `Revision/external_validation_expansion_20261008/results` and `Revision/reviewer_requirements_refined_20261008/annotation_results` when using `verify_release.py`.
